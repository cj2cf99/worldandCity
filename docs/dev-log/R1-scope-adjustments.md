## 2. 关键决定与取舍

1. **选 MIT 的理由**：个人公开项目，要的是简单宽松；仓库不含需要 copyleft 保护的第三方代码（无依赖）。**注意**：MIT 只覆盖代码和本项目自写的数据；将来引入的 Natural Earth（公有领域）、OSM 衍生数据（ODbL，需归属与相同方式共享条款）等不能一概视为 MIT，已在 README 写明并要求登记到 `geo/SOURCES.md`。这是我替用户做的选择，**用户可随时改**，改动面只有 `LICENSE`、`package.json`、种子 `_license`、README 四处。
2. **版权人写 `cj2cf99`**：取自仓库地址与本机 git 用户名，二者一致；未使用任何真实姓名或联系方式（公开仓库红线）。
3. **视觉后置不删需求**：PRD §0-2 与 §21 的要求保持，只后移交付时间；PRD 本身**未修改**（它是需求源文档，调整记录在决定 0004 与里程碑中）。
4. **不为尚未实现的视觉写抽象或空壳**（场景接口、`waveState` 等仅保留为设计契约），避免死代码。
5. **受阻项的“复查时点”**定为 M1 开工前与 M5 开工前，防止遗留项被遗忘。
