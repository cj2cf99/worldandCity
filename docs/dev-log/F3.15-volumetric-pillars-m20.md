# F3.15 创生之柱与三叶星云 M20 的体积渲染重建

- 里程碑：M3 ／ 日期：2026-11-11 ／ 提交：未提交（工作区） ／ `git log --grep "F3.15"` 提交后可查
- 对应需求：用户两条视觉重建指令（创生之柱；三叶星云 M20）。保留导航、数据、波段切换、标注开关

## 1. 实现（`web/cosmos-models.js`）
- 通用体积着色器：盒体内光线步进（步数按画质 低／中／标准 约 一半／四分之三／全量），逐像素抖动，盒面处密度自然淡出（无矩形边界）；输出预乘 alpha，遮挡先画的恒星。
- **创生之柱**：三根柱由弯曲轴线、颈部收窄、侧向伸出的柱头、椭圆截面（有厚度）、域扭曲＋侵蚀噪声构成；底部合并成尘埃基座；边缘按“靠近表面＋朝上＋噪声”给出局部青白／暖金亮边，其余为深褐尘埃。后景气体盒（青蓝弥散、暖橙／暗红局部、暗尘空洞、无统一中心）＋前景暗尘丝盒，构成前中后层次。原“贴图板”、岩石质感全部移除。四个“波段”改为着色器里的配色／透明度切换。
- **三叶星云 M20**：红色发射气体（多尺度密度、中央偏稀、外缘丝状）＋三条不对称、变宽、带分叉的暗尘带（三维管状密度＋吸收，近黑褐，无纯黑板）＋上方独立的蓝色反射云；恒星为点光源（中心 5 颗亮星＋细小星）。
- 说明文字：NGC 6611 与限制说明移到场景下的“▸ 天文注释”开关与信息卡（种子 v32 更新两条“画面说明”）。

## 2. 验证（预览为软件渲染，约 8 帧／秒，每次重载要等几十秒）
- 无脚本错误；创生之柱：看到三根有体积的深褐尘埃柱、青蓝背景气体、局部青白亮边；自动环绕过程中看到过不同角度（有明显厚度）；M20：不规则红色气体、蓝色反射云、暗尘带，拖动后暗尘与气体有视差。
- 种子 v32 导入 118 个节点；测试 49 项通过。
- **未完成／未验证（对照验收标准）**：没有留下“正面／侧面（精确水平 90°）／斜上方”三组规整截图，只有正面与自动环绕中的角度；柱子比真实影像更“圆润”，亮边仍偏粗、偏随机；深入场景（相机进入体积）的视差未单独测；M20 暗尘带偏细、红色区域仍偏圆；两处都有轻微的颗粒状抖动噪点（低步数时更明显）；真实 GPU 的帧率未测（体积着色器较重，已提供画质分档，但低档的外观未看）；移动端未测。
