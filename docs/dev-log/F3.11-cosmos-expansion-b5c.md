# F3.11 宇宙层级扩展 B5c：M51＋NGC 5195、M104、博奥特空洞

- 里程碑：M3 ／ 日期：2026-11-11 ／ 提交：未提交（工作区） ／ `git log --grep "F3.11"` 提交后可查
- 对应需求：用户批准清单 [06](../06-cosmos-p1-candidates.md) 的 B5c；计划 [05](../05-cosmos-expansion-plan.md) §5

## 1. 做了什么
- `seed/nodes.public.json`（v28）：`cel.observable` 下新增 `cel.m51`、`cel.m104`、`cel.bootes-void`（新类型 `void`），`cel.m51` 下新增 `cel.ngc5195`；含简介／离我们／有多大／小知识／画面说明。
- `web/cosmos-models.js`：新增 `spiralGal`（对数螺线＋核球＋HII 结，可设臂数、倾角、方位）与三个场景：`buildGalaxyPair`（M51 双主旋臂、近正面；NGC 5195 光滑伴星系；潮汐桥）、`buildSombrero`（近侧视盘、大核球、一圈暗色星云片组成的暗尘带、上千个球状星团点）、`buildVoid`（“密度场×空洞遮罩”的星系样本，没有壳或边界线，空洞靠星系变稀暗示）。
- `web/cosmos.js`：新增三个层级（`gx` 独占显示，尺度轴放在最内侧 −2／−3，避免与室女座、超星系团等层级叠加——初版放在 9.1 时它们的辉光会以 25% 透明度叠进来）；`cel.ngc5195` 映射为 M51 场景的第 2 个缩放目标；这几个场景（含 M87* 近景）不显示银河带背景（`EXTERNAL`）。
- `web/main.js`：`void` 类型的图标与中文名；`tests/seed.test.mjs`：节点数 83→87。

## 2. 科学近似与限制
- 三个都是程序化示意，信息卡与页面底部都写明；位置与距离为常用文献近似值，未联网对照。
- 博奥特空洞的星系分布不是实测，边界没有画线；侧视的暗尘带是“屏幕朝向的暗色片”，转到别的角度只是一圈暗斑。

- `npm test` 49 项通过；语法检查通过；`npm run db:seed` 导入 87 节点。

- **未验证**：`/n/cel.ngc5195`（映射到 M51 场景缩放目标）；空洞调稀（样本数 11000、遮罩更强）后的效果；手机；各缩放倍率。

## 4. 合规检查
- 需求遗漏：清单中 C 类三个对象均有节点与场景；总纲对 M51“伴星系潮汐特征”“M104 一眼可见暗尘带＋核球”已用示意方式满足。
- 需求偏移：未改既有导航路径；父节点用 `cel.observable`（未建“其他著名河外星系”虚拟分类，计划 §3-② 的决定）；不新增视觉债务。
- 最简化设计：一个螺旋生成函数＋三个场景构建函数；无新依赖。
- 检查中发现并处置：初版层级放在 L=9.1 导致叠入室女座层辉光（白色椭圆斑），改到 −2／−3；M104 初版倾角方向弄反（成了正面），改为近侧视；M51 倾角按“近正面”重算；屏幕中心偏移已按两个星系的中点调整。
