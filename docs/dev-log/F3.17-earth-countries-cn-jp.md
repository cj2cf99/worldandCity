# F3.17 回归地球：全部国家基础层＋中国省／地级＋日本都道府县／主要城市

- 里程碑：M3（地理核心）／ 日期：2026-11-11 ／ 提交：未提交（工作区）
- 对应需求：用户指令“回归地球内部，扩展中国和日本的层级，并扩展所有国家的基础层”；范围由用户选定：中国＝省＋地级市；日本＝都道府县＋政令指定都市等主要城市；国家＝国家节点＋大洲＋中文名。

## 1. 数据与脚本
- `scripts/build-countries.mjs`：6 大洲＋196 个国家（联合国会员国＋梵蒂冈＋巴勒斯坦＋科索沃）写入种子；中文名取自 Node `Intl.DisplayNames`（CLDR）、英文名放 `name_local`；同时生成 `web/iso.js`（ISO2→底图数字编码，194 个可点选）。属地（格陵兰、波多黎各等）与台湾／港／澳（归在中国节点下）不单列；科索沃、图瓦卢在底图里没有对应要素，只有节点。
- `scripts/build-cn-seed.mjs`：读 `fetch-geo.mjs` 下载的 DataV 文件，生成 34 个省级（ISO 3166-2 代码）＋ 476 个地级／区节点（直辖市与港澳下一级为“区”）；西安市／未央区沿用原节点。已下载 33 个省的下一级几何（台湾无数据，无子节点）。
- `scripts/build-jp.mjs`：47 个都道府县＋74 个市／区节点（20 个政令指定都市、各县厅所在地、东京 23 区），并把用户同意下载的 `japan.topojson`（dataofjapan/land，基于地球地图日本，约 415 KB）转成 `web/public/geo/jp/392.json`（约 0.6 MB，精度约 1 km）。**几何文件不入库**；出处登记在 `web/SOURCES.md`，使用需标注出处。
- 种子 v40，944 个节点（地理 834＋宇宙系 110）；每次运行生成脚本会把种子版本加 1。

## 2. 前端
- `web/iso.js`：国家码映射抽成小表，`geo.js` 与 `main.js` 共用（首屏壳不必载入底图）。
- `web/layers.js`：一级几何改为“国家 → [目录, 文件]”表（中国、日本）；选中没有自己几何的节点（日本的市／区）时聚焦到所属有几何的区域；聚焦只取多部分区域里面积最大的一块（东京都不再被小笠原诸岛拉远）。

## 3. 验证
- 测试 49 项通过（更新了 3 处节点数断言与国家列表断言）；`npm run guard` 通过。
- 预览：世界地图上全部国家有色；6 大洲各列出国家（亚洲 48、欧洲 45、非洲 54、北美 23、南美 12、大洋洲 14）；日本下展开 47 个都道府县，东京都下 23 区；深链到新宿区能聚焦到东京都本岛。过程中发现并修复：日本几何的退化小环导致 d3 报错。
- **未验证**：中国新增省份的地图聚焦（只在代码层面沿用原有逻辑，没有逐个点击）；国家地图的点选高亮（194 个国家的颜色／悬浮提示）；非中日国家点开后只有底图与自身轮廓（没有下一级）；移动端；真机加载（日本几何 0.6 MB、中国全国 0.4 MB，按需加载）。

## 7. 清理语句改造（同日）
- `scripts/seed.mjs`：先查出库里 `origin='seed'` 的旧 id，在内存里算出种子已移除的 id；按深度从深到浅、每批最多 90 个、同批同深度，生成多条 `DELETE … WHERE id IN (…) AND NOT EXISTS 子节点`，仍在同一个批处理事务里。保持原语义：user 节点不动，有子节点的保留。
- 测试：新增“清理整条已移除分支”（371 个节点，父／子／孙，超过单批上限）并断言每条删除语句的绑定参数 ≤100；测试 50 项通过。
- 仍未覆盖：上传节点的批处理（944 条 INSERT 的一个 `db.batch`）在真实 D1 上是否有语句数／体积上限，未实测，部署前需要验证。

## 8. 缺陷修复：滚轮跳级、局部地图缩放无效（同日）
- 滚轮跳级：原来地球仪处向内滚直接选第一个子节点；扩展国家后，亚洲的第一个子节点变成拼音第一的国家，于是 世界 → 亚洲 → 阿富汗，既跳过了“展开成世界平面图”，落点也不对。现在：地球仪处向内滚 → 先展开成世界平面图（不换节点）→ 再向内进入大洲 → 再进入该大洲的代表国家（亚洲→中国、欧洲→法国、非洲→埃及、北美→美国、南美→巴西、大洋洲→澳大利亚；找不到则取第一个子节点）。
- 局部地图缩放无效：右侧“主动放大”滑块只作用于 3D 画布（地球仪／世界平面图），国家及以下的平面 SVG 地图没有接上，并且 3D 画布在进入局部地图后会暂停渲染。现在滑块同时写入 `--zf`，`#layers` 用 CSS `scale` 以可用区域中心为原点缩放（`--zo` 由 `layers.js` 设置）；点选、悬浮不受影响。
- 验证：预览里模拟三次向内滚轮，状态依次为 地球仪 → 平面世界图 → 亚洲 → 中国；局部地图下把滑块设为 +100%，`#layers` 的计算样式 `scale` 为 2。**未验证**：缩放后的视觉观感与边缘裁切、缩小到 −50% 时的外观、触摸捏合缩放（仍沿用“上一级／下一级”）、真机滚轮惯性。
