# F3.17 回归地球：全部国家基础层＋中国省／地级＋日本都道府县／主要城市

- 里程碑：M3（地理核心）／ 日期：2026-11-11 ／ 提交：未提交（工作区）
- 对应需求：用户指令“回归地球内部，扩展中国和日本的层级，并扩展所有国家的基础层”；范围由用户选定：中国＝省＋地级市；日本＝都道府县＋政令指定都市等主要城市；国家＝国家节点＋大洲＋中文名。

## 1. 数据与脚本
- `scripts/build-countries.mjs`：6 大洲＋196 个国家（联合国会员国＋梵蒂冈＋巴勒斯坦＋科索沃）写入种子；中文名取自 Node `Intl.DisplayNames`（CLDR）、英文名放 `name_local`；同时生成 `web/iso.js`（ISO2→底图数字编码，194 个可点选）。属地（格陵兰、波多黎各等）与台湾／港／澳（归在中国节点下）不单列；科索沃、图瓦卢在底图里没有对应要素，只有节点。
- `scripts/build-cn-seed.mjs`：读 `fetch-geo.mjs` 下载的 DataV 文件，生成 34 个省级（ISO 3166-2 代码）＋ 476 个地级／区节点（直辖市与港澳下一级为“区”）；西安市／未央区沿用原节点。已下载 33 个省的下一级几何（台湾无数据，无子节点）。
- `scripts/build-jp.mjs`：47 个都道府县＋74 个市／区节点（20 个政令指定都市、各县厅所在地、东京 23 区），并把用户同意下载的 `japan.topojson`（dataofjapan/land，基于地球地图日本，约 415 KB）转成 `web/public/geo/jp/392.json`（约 0.6 MB，精度约 1 km）。**几何文件不入库**；出处登记在 `web/SOURCES.md`，使用需标注出处。
- 种子 v40，944 个节点（地理 834＋宇宙系 110）；每次运行生成脚本会把种子版本加 1。

## 2. 前端
- `web/iso.js`：国家码映射抽成小表，`geo.js` 与 `main.js` 共用（首屏壳不必载入底图）。
- `web/layers.js`：一级几何改为“国家 → [目录, 文件]”表（中国、日本）；选中没有自己几何的节点（日本的市／区）时聚焦到所属有几何的区域；聚焦只取多部分区域里面积最大的一块（东京都不再被小笠原诸岛拉远）。

## 8. 缺陷修复：滚轮跳级、局部地图缩放无效（同日）
- 滚轮跳级：原来地球仪处向内滚直接选第一个子节点；扩展国家后，亚洲的第一个子节点变成拼音第一的国家，于是 世界 → 亚洲 → 阿富汗，既跳过了“展开成世界平面图”，落点也不对。现在：地球仪处向内滚 → 先展开成世界平面图（不换节点）→ 再向内进入大洲 → 再进入该大洲的代表国家（亚洲→中国、欧洲→法国、非洲→埃及、北美→美国、南美→巴西、大洋洲→澳大利亚；找不到则取第一个子节点）。
- 局部地图缩放无效：右侧“主动放大”滑块只作用于 3D 画布（地球仪／世界平面图），国家及以下的平面 SVG 地图没有接上，并且 3D 画布在进入局部地图后会暂停渲染。现在滑块同时写入 `--zf`，`#layers` 用 CSS `scale` 以可用区域中心为原点缩放（`--zo` 由 `layers.js` 设置）；点选、悬浮不受影响。
- 验证：预览里模拟三次向内滚轮，状态依次为 地球仪 → 平面世界图 → 亚洲 → 中国；局部地图下把滑块设为 +100%，`#layers` 的计算样式 `scale` 为 2。**未验证**：缩放后的视觉观感与边缘裁切、缩小到 −50% 时的外观、触摸捏合缩放（仍沿用“上一级／下一级”）、真机滚轮惯性。

## 9. 缺陷修复：放大后整屏“反色”、缩小后露出空白（同日）
- 现象（用户截图）：局部地图放大后，海面与邻县全是一片橄榄色，只有选中的县和个别县有轮廓；缩到 −50% 时地图只占屏幕中央一个矩形。
- 原因 1（反色）：日本几何里，同一个都道府县的各个多边形绕向不一致，d3 把绕向反了的块当成“整个球面减去该块”，铺满整屏（中国数据里也有 2 块：浙江省、泸州市）。原先只按“整个要素”判断绕向，纠正不了。→ `layers.js` 改为逐个多边形校正；`build-jp.mjs` 在生成时统一绕向并去掉面积为 0 的退化环（626 个多边形，反色 0 个）。
- 原因 2（国家整体轮廓盖住海面）：国家级底图（Natural Earth）与都道府县几何精度不同，有下一级几何时，国家整体的填色／描边不再绘制。
- 原因 3（缩小露出空白）：缩放滑块原先缩放整个 `<svg>`（连海洋底色一起缩小）。→ 改为只缩放内部的地图内容组（`.zoomg`，以可用区域中心为原点），海洋底色始终铺满整屏；邻国底图范围改为至少覆盖“缩到 −50%”时的整屏（把整屏以放大中心为原点扩大 2.2 倍后反算经纬度范围）。
- 验证：脚本检查日本多边形绕向全部正确；预览里把秋田县设为聚焦：海面是蓝色、邻县（青森、岩手）正确分块、没有整屏铺色。**未验证**：−50% 时邻国是否把整屏完全盖住（预览是后台窗格，局部地图的过渡不会自己走完，我强制显示了 SVG 层，只看了聚焦县的画面）；其他国家（无下一级几何者）缩小后的覆盖；性能（缩小时邻国路径更多）。

## 10. 平铺地图交互重做、Mercator、加载机制（同日；**交互部分未能在预览里实际操作验证**）
- **投影**：平铺世界图由 Mollweide 改为 Web Mercator（极区截断 ±80°）：等角，聚焦时局部形状不再拉伸、扭曲；横向可无限拼接。3D 展平用的顶点位置、拾取反算、取景计算全部改用新投影（`geo.js`：`flatXY`／`flatInv`／`FLAT_W`／`FLAT_H`，原 `mollweide*` 删除）。
- **拼合**：地图网格左右各一份拷贝（仅展平后可见）；平移时 x 方向按世界宽度折回，拖到边缘时自动接上；纵向限制在极区截断内。
- **操作**：单击国家 → 聚焦（平移到屏幕正中、国家占可用区域约 50%），不进入；双击 → 进入国家内部（原有的过渡：镜头推近后淡入局部 SVG）；聚焦状态下滚轮向上 → 进入国家内部；拖拽 → 平移地图（拖动超过 6 像素才算拖，不会误触点击）；聚焦状态下滚轮向下 → 回到上一级。导航树里点国家仍是直接进入。
- **加载机制**：进入平铺地图时只有地球仪与国家级底图（world-atlas）；局部地图模块 `layers.js` 与下一级几何改为**第一次真正进入国家及以下时才加载**（世界／大洲不加载）；每进入更深一级（或换国家）至少 1 秒的进场动画（顶部进度条），几何在这一秒里加载。
- **缩放范围**：滑块改为 −200% … +200%（正：放大 1…3 倍；负：缩小 1…1/3，对称；原 −50% 为 0.5 倍，现在 −50% 为约 0.67 倍）。邻国底图范围随之覆盖到缩小 1/3 时的整屏。**注意**：我把“缩小极限改为 200%”理解为与放大对称的 −200%（1/3）；如果你想要的是别的数值请告诉我。
- **澳大利亚**：国家取景原先把麦夸里岛、豪勋爵岛等远方小岛算进范围，澳大利亚本体被缩小并偏离中心。→ 新增 `mainFeature`（去掉面积不足最大一块 0.5% 的小块）用于取景与居中；国家轮廓仍完整绘制。
- **第二层级复查**：脚本核对中国全部省的下一级文件：节点名与几何要素一一对应（无遗漏、无多余）；日本都道府县与节点一致；逐多边形校正绕向后无反色块；仍有极少数面积为 0 的退化小块（湖南 1、重庆 1、四川 5、香港 15 个，多为小岛，被取整合并），不影响显示但属于“不完整”。
- **未验证（重要）**：预览窗格在后台时浏览器不派发动画帧，场景循环不前进，因此单击聚焦、双击进入、滚轮进入、拖拽平移与拼合、1 秒进场动画都**没有实际操作过**；唯一看到的是静态的 Mercator 世界图（含左右拷贝）。此前一次对澳大利亚的单击没有触发聚焦，原因没有查明。澳大利亚的局部地图也没有再看。需要你在真实浏览器里点一遍。

## 11. 进入国家时的默认展示比例（同日）
- 需求：进入国家内部时，展示对象尽量占屏幕可用区域的 50%，最大不超过 80%。
- 规则（`layers.js` 的 `showFrac`，`globe.js` 的 'auto' 同一公式）：默认长边占 50%；对象很扁长（短边比例小）时放大，直到短边接近 50%，长边最多 80%。省／州层级的聚焦同样套用，不再固定 80%。单击聚焦仍固定 50%。
- 取景对象：有下一级几何时，用它每个要素的“最大一块”作取景范围（DataV 的中国含南海诸岛，范围与底图的国家轮廓不同；去掉远方小块后以大陆为准），取景后重算邻国底图范围。
- 验证：预览里中国进入后，大陆约占可用区域宽 50%、高约 67%；南海诸岛等远方小块会伸出该范围（属于“对象之外”的部分）。**未验证**：其他国家（日本、美国、澳大利亚、俄罗斯等）的默认比例观感；3D 侧 'auto' 与 SVG 侧比例是否完全对齐（3D 用底图国家轮廓，SVG 用下一级几何，可能有细微差别，淡入时可能有轻微缩放）。

## 14. 地球内部地图手势统一（同日）
- 新增 `web/gesture.js`：3D 平铺世界图与局部 SVG 地图共用。
  - 单击（轻点）＝聚焦选中（不进入）；鼠标双击、触屏连点（350 ms 内同一对象）、触屏长按（520 ms，期间移动超过 6 像素则取消）＝进入下一层。
  - 拖拽（超过 6 像素）不算点击，也取消长按；长按触发后吞掉随后的 click。
  - 移动端屏蔽长按菜单：`contextmenu` 在触屏／长按后 `preventDefault`，CSS 关闭 `-webkit-touch-callout`、文字选择与点按高亮，画布 `touch-action: none`。
- 滚轮：聚焦选中某对象时向前滚＝进入；没有聚焦对象时（包括世界平面图、国家内部、大洲）向前滚无效；向后滚回上一级不变；球态下向前滚仍是“展开成平铺图”。进入统一经 `enterOnce`（900 ms 内去重，避免触屏连发多个事件重复进入）。
- 局部地图：单击省／市＝聚焦（地图推近到该区域并高亮，只加载到它的上一级几何，不加载它自己的下一级）；双击／连点／长按／聚焦后滚轮＝进入（加载下一级，带 1 秒进场动画）；点邻国始终是“进入”（换国家）。`layers.update` 增加 `peek` 选项；进场动画的判定改为按“已加载的层数”比较，聚焦后再进入同一对象仍有动画。
- 验证：预览里用合成事件检查局部地图——单击陕西／甘肃一带的省后 URL 与详情卡切换到该省，层数为 1；随后双击，层数变为 2（国家层＋该省的地级层）。**未验证**：真实触屏的长按、连点手感与长按菜单是否被各浏览器完全屏蔽（iOS Safari／Android Chrome 行为不同）；3D 平铺世界图上的这套手势（只改了接线，没在预览里点过）；滚轮在聚焦／无聚焦两种状态下的实际表现。

## 15. 进入动画改为“光点沿边缘跑一圈”（同日）
- 去掉顶部进度条；进入下一层的 1 秒（几何加载期间）改为：一个带光晕的光点沿选定对象的边缘（多块区域取最大一块）每秒跑一圈，加载时间超过 1 秒则继续循环，结束即移除。实现为 SVG 描边路径 + `pathLength` 归一化 + 虚线动画（`layers.js` 的 `g.runner`，样式在 `style.css`）。
- 只在已显示的局部地图内播放（省→市等逐级进入、换邻国）；从 3D 平铺世界图进入国家时 SVG 尚未显示，这一段仍是镜头推近，没有光点。

## 16. 进入动画改为“笔画出内部 SVG”（同日，取代第 15 节的光点）

## 22. 缺陷修复：地图上个别区域发黑（同日）
- 现象：索马里兰（以及其他几个没有编码的要素）在地图上是一块近乎黑色的区域。
- 原因：配色用名字／编码的哈希取色相、饱和度、亮度，哈希是无符号 32 位整数，却用有符号右移 `>>` 取位；哈希值超过 2³¹ 时结果为负，亮度被算成比下限低甚至为负（局部地图里邻国还要再减 10），于是发黑。
- 修复：`geo.js`（3D 平铺图／地球仪的陆地色）与 `layers.js`（局部地图填色）改用无符号右移 `>>>`；个别国家的颜色会因此略有变化。
- 验证：用脚本核对修复前几个无编码要素的亮度偏低（如 23%、17%、9%）；修复后亮度回到设计范围。**未验证**：浏览器里实际观感。

## 24. 缺陷修复：马达加斯加等国局部地图缺块（同日）
- 现象（用户截图）：马达加斯加有 22 个一级行政区，图上只画出五六块，其余成了海面色。

- 修复：`build-adm1.mjs` 里要素的 `adcode` 改为唯一的节点 id；同国重名时附当地语名称区分（如“塔那那利佛省（Bongolava）”），仍重名再加序号；`name_local` 的英文同样附当地名。核对：195 个国家文件里重名 0、重复编码 0。种子 v53。

- 验证：马达加斯加文件 22 个要素名称唯一；测试 50 项通过。**未验证**：浏览器里马达加斯加是否 22 块都画出来；其他国家是否还有同类“缺块”（脚本只查了重名与重码）。
