# F3.10 M87* 与人马座 A* 黑洞近景（实时近似光线追踪）

- 里程碑：M3 ／ 日期：2026-11-11 ／ 提交：未提交（工作区） ／ `git log --grep "F3.10"` 提交后可查
- 对应需求：用户提供的《M87* 与人马座 A* 高品质实时黑洞特效 V2.0》；取代 F3.5／F3.6 里“黑洞只是定位标签”的做法

## 1. 做了什么
- `web/cosmos-models.js`：新增 `buildBlackHole(kind)` 与着色器。全屏一张四边形，逐像素对光线按偏折方程 a = −1.5·h²·x/r⁵（rs=1）积分：得到黑洞阴影、光子环附近的多重成像、被弯到阴影上方的盘背面、相对论性多普勒不对称与引力红移；盘按开普勒速度差速转动，湍流纹理在转动坐标系里采样（因此被拉伸、剪切），另有按轨道运动的短寿命亮斑。
- 两个黑洞参数完全不同：M87*（盘较宽、慢、暖白琥珀，纹理缓慢，2 个亮斑，蓝白／青紫双极喷流——沿自旋轴、近侧更亮、有移动亮结，按直线传播）；人马座 A*（紧凑、约 5 倍快、暖橙琥珀与深红褐，4 个亮斑，间歇性增强，不画喷流）。背景：各自的环境恒星点云（M87 暖白椭球；银心更密的暖色星团），环境放在 20 rs 之外且尺度大幅压缩。
- `web/cosmos.js`：新增层级 `cel.m87-bh`、`cel.sgr-a`（尺度轴 −1，独占显示）；移除它们在 ZOOM_OF 里的旧别名；银河系与室女座场景里的“A*／M87*”标签改成可点击进入黑洞近景。
- `seed/nodes.public.json`（v27）：两个黑洞节点的“画面说明”改写成真实做法。

## 2. 科学近似与艺术边界（页面底部也有声明）
- 近似：无自旋度规的光线偏折（忽略自旋）、薄盘、喷流直线传播（不做透镜）、背景星场只给本画面用。
- 艺术：吸积流纹理、亮斑、A* 的间歇增强、喷流的结构与移动亮结、颜色；动态是加速的观赏时间。科学模式关闭亮斑外的艺术增强（闪耀、喷流结构调制），“动态效果＝关”时画面静止。
- 没有“原静态参考图”（用户未提供），因此无法逐项对照其构图；以“暂停任意时刻都有完整结构”为目标。

## 3. 验证
- 着色器单独编译 0.56 秒（避免再出现上次行星着色器的卡顿）；两个新页面在预览里渲染正常、控制台无错误：A* 呈现阴影、盘背面被弯到上方、左右亮度不对称、琥珀色；M87* 呈现阴影、倾斜的盘、上下双极喷流。
- **未验证**：真实 GPU 上的帧率（预览窗格不出稳定帧，无法测）；移动端；各视角（只见了自动环绕的一两个角度）；喷流宽度与亮度只调整过一次、凭观感；星系全景→中景→近景的过渡动画；“科学模式”与“动态效果＝关”的画面。

## 4. 合规检查
- 需求遗漏：阴影、背面像、前景倾斜盘、多重成像、不对称增强、湍流、差速、亮斑、喷流（M87*）、间歇增强（A*）、两套不同参数、三级镜头（星系场景标签→缩放→近景；近景内可用缩放滑块拉远看环境）均有；**未做**：喷流粒子的 GPU 更新（改用体积积分）、对其他图层的透镜（背景星云不被弯折）、自旋。
- 需求偏移：与“用 M87 星系暖白背景／银心暗尘”略有差距：A* 的暗尘结构未做（只有暖色星点）。
- 最简化设计：一个着色器＋一个构建函数＋两组参数；无新依赖。
- 检查中发现并处置：无阻断问题；喷流初版过宽过糊，已收窄并加亮。
