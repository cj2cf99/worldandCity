## 1. 做了什么（文件清单与职责）

- `seed/nodes.public.json`：本星系群下新增 `cel.m31`、`cel.m33`、`cel.lmc`、`cel.smc`（kind=`galaxy`），每个含简介／离我们／有多大／小知识／画面说明（数据等级：位置近似＋形态示意）；版本升到 22。
- `web/cosmos.js`：`ZOOM_OF` 把这四个节点映射到“本星系群场景＋缩放目标序号”（1 M31、2 M33、3 LMC、4 SMC）；`LEVEL`、初始 `cur`／`zsel`、`focus()` 通过 `resolveNode` 处理映射。
- `web/cosmos-models.js`：本星系群的缩放目标增加 LMC、SMC；把原来合并的“大、小麦哲伦云”标签拆成两个可点击标签。
- `scripts/seed.mjs`：版本升级导入时，删除“种子里已不存在、origin=seed、没有子节点”的行（user 节点不动）——此前奥陌陌、旧“宇宙网”节点会残留在开发库里。
- `tests/seed.test.mjs`：节点数 59→63；新增“删除已移除叶子节点、保留 user 节点”测试。

## 2. 关键决定与取舍

- 不为这四个星系各写渲染器：本星系群场景里已有 M31（大斜盘、核球、尘埃带、伴星系）、M33（絮状旋涡）、LMC／SMC（不规则）的程序化模型，新节点只落在该场景并放大。
- 不新增 `virtual_collection` 节点、关系表、数据契约字段（见计划 §3）。
- 导入器删除逻辑只删叶子：有子节点的旧行保留，避免外键错误；这是为了让开发库与种子一致，不是通用迁移机制。
