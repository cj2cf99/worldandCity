## 2. 实现（`web/cosmos-models.js` 的 `photoLayers`／`photoNebula`；`web/cosmos.js` 相机限制）
- 加载后在浏览器里把一张图拆成：**后层**（去星后的发光气体，暗尘处提亮，模拟“尘埃后面还有光”）、**前层暗尘**（按亮度得到的暗尘密度，放在更靠前的深度）、**亮星层**（高通滤波取点光源，相加混合）、**环境层**（同图大尺度柔化，边缘按噪声不规则淡出）＋远景环境＋极淡前景薄雾（极慢漂移）。各层边缘按噪声羽化，没有矩形边界。
- Z 布局：远景 −9、环境 −2.4、后层 −1.6、前层暗尘 +0.9、亮星 +1.8、薄雾 +3.2；相机限制在水平 ±0.3 弧度（约 17°）、垂直 ±0.2 弧度（约 11°），不能绕到侧面；鼠标微视差沿用。
- 创生之柱保留“波段”切换（哈勃／韦伯两套图）、主柱／次柱／小柱标签、可开关的“天文注释”（NGC 6611 等长说明移到注释里与信息卡）。马头星云可点标签放大到马头。
