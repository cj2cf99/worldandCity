## 1. 做了什么
- **节点（seed v30，共 103 个）**：新增 `cel.galactic-disk`、`cel.multistars`（导航分组）、`cel.m8`、`cel.m20`、`cel.carina`、`cel.horsehead`、`cel.trapezium`、`cel.ngc6611`、`cel.veil`、`cel.tarantula`、`cel.r136`、`cel.kepler16`、`cel.algol`，并补上 `cel.sag-car-arm`、`cel.m16`、`cel.pillars`；`cel.m1`、`cel.ngc7293` 改挂到 `cel.galactic-disk`。
- **创生之柱（最高优先级）**：2.5D 分层——背景发射层＋三根尘埃柱本体（程序化细碎纵向尘埃纹理）＋电离边缘＋前景暗尘，加年轻恒星／柱顶“蛋”／一条极短喷流；设置面板新增“创生之柱波段”四档（可见光、近红外、中红外、艺术增强），每档改变各图层的权重、色调和混合方式。
- **其他星云**：M42（四颗主星、蝙蝠翼气体、猎户之棒、暗尘“鱼嘴”、M43 反射区）；马头（暗尘剪影＋后方红色发射）；M16（IC 4703 与 NGC 6611 分开标注，创生之柱位置标记可点击进入）；M8（宽阔气体＋沙漏核心＋暗尘带）；M20（红色发射、深色三叶暗带、蓝色反射）；船底座（暗金气体、巨大空腔、海山二）；蜘蛛星云（R136 致密星团、丝状弧）；蟹状星云（交织的红橙丝、青蓝高能伪彩、脉冲星 1 秒一次的放慢闪动）；面纱（东弧／西弧／皮克林三角的细丝）；螺旋星云（青蓝内环、橙红外环、气体结、中心白矮星）。
- **多恒星系统**：通用 `buildMulti`：开普勒轨道、围绕共同质心；半人马 α A/B（79.9 年，e=0.52；比邻星太远只作文字标注）；天狼星 A/B（50.1 年，e=0.59）；Kepler-16（互绕双星＋环双星行星，双光源着色，含光变曲线）；大陵五（内双星 2.87 天互掩食、外成员压缩显示、光变曲线）。时间与全局模拟时间倍率联动，暂停＝静止；轨道线归“参考线”开关。
- 父场景里的相应标签改成点击进入：猎户臂（M42、船底座、M16、天鹅圈、M1、M8、M20、螺旋星云、马头）、恒星邻域（半人马 α、天狼星）、本星系群（蜘蛛星云）。

## 2. 科学近似与限制（页面与信息卡均有说明）
- 星云：概念三维＋艺术增强，位置与距离为文献近似值；创生之柱与马头用程序化画出的轮廓，不是观测图像，也不是真三维。**没有嵌入任何哈勃／韦伯图像**，“波段”切换只是图层权重与配色示意。
- 多恒星系统：轨道参数取文献值；恒星显示半径放大（40／30／6／3 倍）；天狼星 A/B 的真实半径差约 200 倍，画面压缩；大陵五外成员轨道按 0.075 压缩；Algol 的物质转移、Kepler-16 凌星时的细节视觉、比邻星 b 等都没有画。
- 星云没有真实演化动画：只有极低幅度的边缘微光、年轻恒星微闪、脉冲星放慢闪动、螺旋星云外壳极缓慢扩张。

## 3. 验证
- `npm test` 49 项通过；语法检查通过；`npm run db:seed` 导入 103 节点；提交守卫通过。
- 预览：创生之柱、马头、Kepler-16 看了画面（三根柱＋边缘光；马头剪影＋红色背景；双星＋行星轨道＋光变曲线）；另外 12 个场景（M42、M16、M8、M20、船底座、蜘蛛星云、M1、面纱、螺旋星云、半人马 α、天狼星、大陵五）通过应用内跳转逐个加载并运行了数秒，**没有任何脚本错误**，但其中除大陵五外都没有看画面。

## 4. 合规检查
- 需求遗漏：4 个多恒星系统、10 个星云、3 个子节点（梯形星团、NGC 6611、R136）、创生之柱专项均有；**未做**：观测图像／三维切换（无图像来源）、每个对象的五种专属镜头（只有创生之柱以外都没有；创生之柱也只有默认视角＋波段切换）、“边缘特写／恒星形成视图／多波段对比”三个专属镜头、多波段滤镜说明文字、物质转移、船底座的大质量恒星活动示意、蟹状星云的膨胀时间压缩、R136 与梯形星团的“内部子场景”（只做成缩放目标）。
- 需求偏移：星云全景里没有为每个星云画简化标记（沿用既有猎户臂场景里的星云）；分组节点（银河盘等）是导航入口，没有画壳层。
- 最简化设计：一套通用多恒星构建函数＋10 个星云构建函数＋共用的几个小工具；无新依赖；没有拆成 V1／V2 两遍。
- 检查中发现并处置：创生之柱初版边缘过亮过粗（卡通感）、背景板有硬边、底部被切平 → 改为更细的边缘、渐隐背景与底部；初版“多边形”柱顶像小球 → 缩小融合。
