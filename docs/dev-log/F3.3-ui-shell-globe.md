## 8. 更正：局部平面地图改为静态 SVG（取代 §7 中“与 3D 同投影逐帧同步”的做法）
- 原因（用户反馈）：Mollweide 离中央经线越远越倾斜，放大到省／市时“斜着”；逐帧同步的全屏 SVG＋滤镜／脉冲动画造成整屏闪烁。
- 现做法：国家及以下用以国家为中心的圆锥等积投影（正对屏幕）的静态 SVG；聚焦用 CSS 变换过渡；勾边为“宽淡光晕＋清晰细线”两条静态路径，无滤镜、无动画；局部地图显示后 3D 画布淡出并暂停渲染。世界／大洲仍在 3D 地球仪／世界平面图上。
- 验证：内置浏览器中西安市视图正对屏幕、13 个区县与金色勾边清晰，控制台无错误；**闪烁是否消除需在用户机器上确认**（内置浏览器为软件渲染，不能代表真实 GPU）。
- 未验证：非中国国家（如法国）的局部视图、跨 180° 经线的国家、窗口缩放后的重排。

## 9. 层级切换动画（亚洲→中国等），用户反馈“缺少流畅过渡／要先对齐再切换”
- 地球仪→局部地图：不再展开世界平面图。流程：地球仪转向选中国家 → 镜头推近，距离按“该国范围恰好占满可用区域”解算（与局部地图拟合一致），并用视图偏移把国家放到可用区域中心 → 仪轨与球内展品退场 → **等转向／推近／聚焦全部落定**（`scene.settled` 回调，不用定时器，慢设备也不错位）→ 局部 SVG 带轻微缩放淡入，3D 同时淡出并暂停。
- 局部地图内换级（省→市→区）：镜头用 CSS 变换平滑缩放；只有新出现的一层淡入，已有层不重绘；勾边淡入。
- `viewRect` 由 3D 与局部地图共用，保证两边“可用区域”一致。
- 验证：内置浏览器中亚洲→中国后整个中国完整居中显示；**过渡的流畅度（帧级）在软件渲染的内置浏览器里无法评估，需在用户机器确认**；投影不同（球面透视 vs 圆锥等积），切换瞬间只能保证位置和大小近似对齐，形状仍有细微差别。

## 10. 动画规范与去跳变（用户决定：所有动画 1–3 秒，艺术性与表现性优先）
- **时长规范**：所有状态转场 1–3 秒（面板 1.2–1.4 秒＋错峰延迟，总长 ≤3 秒；局部地图交叉淡化 2 秒、缩放落定 2.4 秒；镜头聚焦 1.4–1.6 秒；俯冲 1.6 秒；展开 2.4 秒／收回 1.8 秒；悬停反馈也为 1 秒）。循环类氛围动画限定在 1–3 秒周期（徽标旋转 3 秒、摇曳／浮动 3 秒等）。例外：`prefers-reduced-motion` 下压到近 0（可访问性，保留）。滚轮／双指一次手势后冷却 1.5 秒，避免动画未播完就叠下一级。
- **去跳变**：局部地图换级时旧图层不再瞬间消失，而是淡出 1.3 秒后移除；新一层与新勾边淡入；同一国家内复用已绘制的底图与层级组，只重绘变化部分。
- 验证：脚本驱动滚轮进出一级，DOM 中确认旧层/旧勾边带 `out`、新层带 `new`，随后清理；**视觉流畅度仍需在用户机器确认**（内置浏览器为软件渲染）。

## 11. 宇宙系（地球以外）——用户追加需求
- **领域分离**：地球仪继续缩小进入宇宙系；宇宙系用独立场景 `web/cosmos.js`，进入后释放地球场景、纹理、局部地图图层与缓存（`disposeEarth`），深链接直达宇宙节点时地球侧完全不加载。`geo.js` 的底图 ES 模块在页面存活期内仍驻留内存（浏览器无法卸载模块），整页刷新才释放。
- **数据**：种子 v3 增加天体链（`realm='celestial'`）：可观测宇宙→更大尺度宇宙→银河系→恒星邻域→太阳系→太阳／地月系统→月球；导入器支持 `detail`。天文数值均为公开通用值并标明性质（估计值／定义值／平均值）。层级只是浏览尺度，不是严格包含关系（PRD §6）。
- **表现**：天体走写实风格（程序生成材质，无外部素材）；距离与比例以画面优先，**不是真实比例**。地球（昼夜／云／夜灯／大气）、月球（陨石坑／月海）、太阳（米粒组织／黑子／日冕）、行星（云带、土星环）、银河系旋臂、恒星邻域、宇宙网、可观测宇宙边缘（CMB 球壳）。六＋一个尺度层级在同一场景里做“十的幂”式推拉（2.2 秒）。界面换为黄铜／暖金／衬线的“古典天文仪器”语言；地球仪的环在进入宇宙系时收起（2 秒）并不再使用。
- **手势**：滚轮／双指在地球仪处缩小进入宇宙系，在地月系统放大回到地球；地球仪与宇宙系均可拖拽旋转（方向跟手，带惯性；触屏单指同样）。
- 修复：背景“银河带”在银河系以上的层级不再出现（原先像灰白雾圈）。
- 未验证：宇宙场景的帧率与低端设备显存、触屏拖拽、地球⇄宇宙的交叉淡化在真机上的流畅度（内置浏览器为软件渲染）；银河系与可观测宇宙之间的中间层级尚未建节点（见回复中的清单）。

## 12. 银河系亮点闪烁（用户反馈：严重）
- 原因：点精灵约 1 像素，随旋转／镜头漂移在像素格间跳动；合成通道无抗锯齿；泛光放大了闪烁的亮点。
- 处理：点着色器设最小 2.2 像素并按面积压低亮度（总能量守恒）；`EffectComposer` 渲染目标改为 4 倍多重采样；银河／邻域／宇宙网自转与镜头漂移放慢；点叠加亮度与泛光阈值调低；移除恒星邻域的距离参考环。
- 验证：内置浏览器中银河系视图渲染正常、控制台无错误；**闪烁是否消除需在用户机器确认**（软件渲染下无法评估逐帧闪烁）。

## 13. 宇宙系大扩展（本会话后半段，均为用户逐条指示）
- **层级**：天体链扩到 48 个种子节点（v8）：月球、地月、太阳、太阳系（8 行星、主要卫星、小行星带＋谷神星、哈雷／海尔-波普／奥陌陌）、奥尔特云、恒星邻域、本地泡、猎户臂、银河系、本星系群、室女座星系团、本超星系团、拉尼亚凯亚、鱼-鲸座复合体、斯隆长城、宇宙网（原“更大尺度宇宙”，改名）、武仙-北冕座长城、可观测宇宙。每个节点带“小白科普”简介，数值标明估计值／平均值／定义值。
- **模型**：每个层级独立建模、按需构建；同一尺度的多个模型用“独占组”，只显示当前节点。行星与卫星有表面级程序纹理（火星峡谷／极冠、木星云带＋大红斑、海王星大暗斑、木卫一火山、木卫二冰裂纹、土卫二喷泉、土卫六雾霾等）；彗星沿真实开普勒轨道，闭合椭圆＝会飞回来，开放双曲线＝一去不返；小行星带为成千块凹凸岩石。银河系改为三维核球＋短棒＋较厚盘＋厚盘＋银晕，去掉硬边界；加入星云（猎户座大星云、玫瑰星云、北美洲星云、昴星团、船底星云、鹰状星云等）与暗色尘埃带；本星系群重画并加入麦哲伦云与麦哲伦流；本超星系团改为向室女座星系团聚拢的蛛网，拉尼亚凯亚改为分瓣的区域＋细流线＋沿流线流动的亮点（依据 Tully 2014 的描述）。
- **宇宙网与可观测宇宙**：用三维 Worley 噪声着色器画丝带与节点，**启动时一次性烘焙成球面贴图**（每帧仅一次采样，球仍是 3D、可拖拽旋转）；可观测宇宙为紫粉发光的网球，内嵌旋涡星系。
- **可观测宇宙彩蛋（人影、巨手、烟雾、红眼）已按用户要求整体移除**：程序绘制的 2D 图层风格太差。若要重做，应改用用户提供的插画素材（不入库）并保持球体可旋转。
- **未验证／已知问题**：内置浏览器为软件渲染，烘焙与渲染极慢，**许多层级未能逐一目测**（行星、卫星、小行星带、彗星、星云、本星系群新版、超星系团新版、本地泡新亮度、导航自适应宽度）。观测宇宙层只看到了前半段动画（球、烟雾、红眼、手的轮廓），**手最终“抓握”姿态未目测**。烘焙在低端设备上会有一次性启动开销（观测宇宙 3 张贴图，宇宙网 3 张）。
- 用户质疑“看着太阳怎么就进入地月系统”：脚本验证路径不会跳转（太阳系↔太阳↔回太阳系）；截图中的“太阳”其实是太阳层级的淡出鬼影，已用阈值截断。

- 按用户要求，“宇宙网”一层环绕相机的 Worley 特效背景壳已去掉，该层现仅保留散布的旋涡星系与标注；可观测宇宙的发光网球（球体本身）保留。
- 按用户要求，可观测宇宙的“发光网球”（Worley 烘焙壳、内嵌星系与粉紫气体）也已移除，连同烘焙代码一起删除；该层现仅有宇宙微波背景的球壳、球心标记与标注。
- 本超星系团改为按《室女座超星系团示意图》（Atlas of the Universe）的布局重做：圆柱形示意体积，本星系群居中偏左（红色标注），室女座星系团居右，猎犬座／大熊座／狮子座 I、II／室女座 III 星系群、M81、M101、半人马座 A、天炉座与波江座星系团等按图中相对位置摆放；深度方向为示意。位置来自对图的目测，非精确数据。
