# 0004 视觉效果后置：用静态内容替代，最后集中调整

- 日期：2026-11-10 ／ 决定人：用户（"先不急着做视觉效果，暂时用静态内容替代，并在开发文档中说明，视觉最终效果在最后集中调整"）
- 影响：里程碑 M2；M3 的聚焦动画；设计 §8.2、§8.5、§8.6；PRD §18.1 的验收归属
- 性质：**用户确认的范围调整，不是需求删除**。PRD §0-2 "不可删除地球仪动画、球面展开……等已确认需求"、§21 "艺术体验真实成立"仍然有效，只是**交付时间后移到最后一个里程碑 M8**。

## 1. 原则

1. 现在不做的是**视觉表现**；**功能与数据结构照常做**（节点导航、API、搜索、标注数据、备份等）。
2. 静态替代物必须**可被替换而不波及功能代码**：沿用设计 §8.1 的目录与场景名，真实场景落地时只替换该场景模块。
3. 静态替代物**不得被当作"视觉验收已通过"**。PRD §18.1 的条目在 M8 之前一律保持未勾选。
4. 不为尚未实现的视觉预先写抽象。场景接口（`init/activate/deactivate/dispose`、`waveState`、`projection` 策略）**保持为设计文档中的契约**，到 M8 再落成代码；现在不写空壳。

## 4. 风险（需要用户知悉）

| 风险 | 说明 | 缓解 |
|---|---|---|
| 视觉最后做，可能发现与功能层不兼容 | 例如投影选择影响底图与标注的坐标变换；地图与 3D 的切换时机影响状态恢复 | 内部数据始终为经纬度、投影只在渲染层（设计 §8.2）；该约定保持；M3 的地图图层不绑定特定投影，投影作为一个函数参数传入 |
| PRD §21 "优先证明艺术体验" 被后移 | 产品最核心的卖点最晚验证 | 这是用户的选择；M8 若失败（如移动端帧率不达标），降级方案为设计 §13 S3 的"遮罩＋镜头过渡" |
| 静态占位被误当成最终效果 | 占位应在页面上显式标注"视觉占位" | 前端壳实现时强制带该标注，并列入 M8 退出清单 |

## 5. 谁来检查

每次涉及前端的功能记录，在"需求偏移"一节必须列出：本功能是否新增了视觉债务、是否使用了占位、占位是否带标注。
